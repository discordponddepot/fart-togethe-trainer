# Security Policy

## Scope

fart-togethe-trainer is a local, single-player oriented trainer for
Fart Togethe. It reads/writes process memory of the game only.

## Reporting

If you find a memory-safety issue (out-of-bounds write, bad pointer
resolution causing the game to crash), open a private security advisory
or email the maintainers listed in `AUTHORS` (see repo settings).

Please do NOT publish working offsets that bypass anti-cheat for
multiplayer modes. Single-player offsets are fine and welcome.

## Supported versions

Only the latest tagged release and `main` receive fixes.
